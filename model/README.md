# Model Directory (학습된 모델 저장소)

이 디렉터리는 "진짜일까? AI 이미지 판별기" 서비스의 TensorFlow.js 전이학습 모델 파일들이 위치하는 폴더입니다.

## 파일 구성
- `model.json`: 모델 아키텍처(구조), 토폴로지 및 가중치 매니페스트 메타데이터
- `weights.bin`: 학습된 레이어의 부동소수점(Float32) 바이너리 가중치

## 내가 직접 학습한 모델로 교체하는 방법
1. 웹사이트의 **[모델 학습하기 (train.html)](/train.html)** 페이지로 이동합니다.
2. "실제 사진"과 "AI 생성 이미지"를 각각 여러 장 업로드합니다.
3. **[학습 시작]** 버튼을 눌러 전이학습을 진행합니다.
4. 학습이 완료된 후 **[모델 다운로드]** 버튼을 클릭하면 브라우저의 다운로드 폴더에 `model.json`과 `model.weights.bin` 파일이 저장됩니다.
5. 다운로드받은 파일들을 이 `model/` 폴더 안으로 복사하고, 가중치 파일명을 `weights.bin`으로 지정(또는 `model.json` 내의 파일명과 일치)합니다.
6. Git 커밋 후 GitHub에 푸시하면 Vercel에 자동으로 새 모델이 배포됩니다.

> **팁**: 판별 페이지(`index.html`)에서도 서버 파일 변경 없이 브라우저 상에서 다운로드받은 `model.json`과 `weights.bin`을 직접 드래그하여 즉시 테스트해볼 수 있는 수동 업로드 기능을 제공합니다.
